Memory Master - Brain Training Game

Hi! Welcome to Memory Master, a simple and fun memory-matching game I built using React and JavaScript.

I created this project to improve my frontend development skills and practise building an interactive web application. The idea is simple: flip the cards, remember the symbols, and find all the matching pairs.

About the Game

Memory Master is a browser-based game where players match hidden cards. It includes different difficulty levels, a timer, a moves counter, and a best-score feature.

The goal is to match all the pairs using as few moves as possible.

Features

Match hidden cards.

Choose from Easy, Medium, and Hard difficulty levels.

Track your completion time.

Keep track of your moves.

Save your best score in the browser.

View your matching-pair progress.

Restart the game whenever you want.

Play on desktop, tablet, or mobile devices.

Getting Started

Follow these steps to run the project on your computer.

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the Project Folder

cd memory-master

3. Install Dependencies

npm install

4. Start the Development Server

npm run dev

Open the local URL shown in your terminal to play the game.

How to Play

Choose your preferred difficulty level.

Click a card to reveal its symbol.

Click another card to find a matching pair.

Remember the positions of the symbols.

Match all the pairs to complete the game.

Try to beat your previous best score.
